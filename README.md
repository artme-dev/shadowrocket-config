# shadowrocket-config

Итоги сетевых проверок, ограничения экспериментальных профилей и порядок продолжения
работы: [исследование маршрутизации Shadowrocket](docs/network-lab/README.md).
Персональная цепочка через группы проверена на iPhone 2.2.93: IP-маршруты и UDP,
пользователь подтвердил неплохой голос. Mac 2.2.93: полный профиль и нативный UDP проверены; отказоустойчивость проверена
на изолированных маршрутах. После обновления пользователь подтвердил работу финального профиля на iPhone.
[Текущее устройство профиля и порядок проверки](personal/README.md).

Два распространяемых адреса: семейная подписка artem-public (только серверы)
и персональный полный artme.conf в secret Gist (правила, входы, выходы, цепочки).
Персональная сборка описана в [personal/README.md](personal/README.md).

Этот публичный репозиторий содержит исходные правила и сборщик без секретов.
Корневой artme.conf — прежняя версия правил и база сборщика. Полный файл с узлами
создаётся в исключённом из Git out/artme.conf и публикуется отдельно.
Семейная подписка не изменяется персональной сборкой.

## Монитор на Mac

[AI Network](mac-status/README.md) — нативный монитор только для просмотра:
значок в строке меню, выходные IP и свежесть проверок, состояние watcher и службы
kill switch, подробности и копирование диагностической сводки. Работает независимо
от защиты и не меняет конфигурацию. Личная установленная копия: `~/Applications/AI Network.app`.

## Установка персонального профиля

Использовать персональную ссылку полного профиля из приватной публикации:
**Config → Download from URL → Use Config**, затем **Global Routing = Config**.
Настройка групп, обновление, проверочные сайты и откат описаны в
[инструкции](personal/README.md). Публичный корневой artme.conf содержит только
базу правил и не заменяет полный файл с серверами и цепочками.

## Изменения

- `personal/artme.json` — состав входов, порядок AUTO, маршруты категорий.
- `personal/secrets.local.json` — локальные реквизиты; не коммитить.
- `tools/assemble_artme.py` — сборка и проверяемая публикация.
- `tools/validate_artme.py` — проверка связей, правил, TLS и fail-closed.
- `artme.conf`, `rules/zoom.list` — базовые правила сборщика.

Изменение исходников в Git само по себе не обновляет персональную публикацию:
нужны сборка, публикация и обновление Config на устройстве. Семейная подписка
распространяется отдельно и персональных ISP-выходов не содержит.

Не коммитить ссылки подписок, пароли, ключи и полные сгенерированные профили.
