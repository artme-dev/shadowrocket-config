# Единый персональный artme.conf

Два адреса для устройств:

1. `artem-public` — существующая семейная подписка, только серверы. Персональная сборка её не редактирует.
2. Персональный `artme.conf` — один полный файл в существующем персональном secret Gist: правила, серверы, ISP-выходы и цепочки.

Полный файл содержит ключи и пароли и не коммитится в публичный репозиторий.
Secret Gist доступен любому, кто знает ссылку.

## Устройство файла

- `[General]`: исходные DNS-настройки, собственный update-url, `close-if-proxy-chain-missing = true`, отказ от прямого UDP при отсутствии поддержки у выхода.
- `[Proxy]`: пять VLESS и один Hysteria2 из персонального набора, затем отдельные ISP-OPENAI, ISP-CLAUDE, ISP-OTHER. Пока у них одни реквизиты.
- `[Proxy Group]`: artem-personal для входных серверов; SERVICE для выходов; три независимые ENTRY-* для выбора входа; OPENAI, CLAUDE, OTHER для маршрутизации.
- `[Rule]`: исходный порядок и DIRECT-исключения. Прежний PROXY заменён на OTHER. Список IP Zoom встроен в файл.

У каждого ISP-узла задана связь `chain=ENTRY-OPENAI` и соответственно для остальных
категорий. В группах выхода доступны только соответствующий ISP и ручной REJECT.
Другого выходного IP или DIRECT в них нет. Автоматической ротации входов нет.

Начальный вход для всех категорий — BLANC-NEWYORK. При смене входа реквизиты
выходного ISP сохраняются. Hysteria2 присутствует в общем персональном наборе,
но не включён в исходные наборы входов цепочек.

## Что менять

- `artme.json`: набор серверов, отдельный набор входов и начальный выбор каждой категории, ссылки на реквизиты выходов.
- `secrets.local.json`: URLs подписок и реквизиты выходов. Исключён из Git, права 600. Поля: providers.blanc, providers.xeovo, exits.<имя>.server/port/username/password.
- `publish.local.json`: owner и gist существующей персональной публикации. Исключён из Git.
- `../artme.conf`: базовые DNS-настройки и правила для сборки.

Чтобы заменить выход одной категории, добавить запись в exits локального файла
секретов и указать её ключ в artme.json → routes → OPENAI/CLAUDE/OTHER → exit.
Чтобы в будущем убрать ISP у OTHER, нужно явно сменить его политику на ENTRY-OTHER
в генераторе; автоматического резервирования этим путём нет.

## Сборка и публикация

Из корня репозитория:

```
uv run tools/assemble_artme.py
uv run tools/assemble_artme.py --publish
```

Сборщик получает свежие параметры серверов у провайдеров и создаёт out/artme.conf
с правами 600. Публикация обновляет только artme.conf в существующем персональном
secret Gist, не затрагивая другие файлы и семейную подписку. Опубликованный файл
сверяется с локальным содержимым; адрес записывается в out/artme-url.txt.

Изменения исходников попадут на устройство после сборки, публикации и обновления
конфига в Shadowrocket. Свежие ключи Blanc/Xeovo получает сборщик, а не устройство.

## Чистая установка

Config → «+» → персональный URL artme.conf → Download → Use Config.
Global Routing = Config. Отдельные серверные подписки для этого профиля не нужны.
Для сохранённого GEOIP,RU нужна Country-геобаза.

На новом устройстве действуют policy-select-name. Ручной выбор в UI может
сохраняться локально; после изменения исходного начального выбора нужно проверить
фактический выбор группы.

Эта версия подготовлена без сетевых тестов по просьбе пользователя. Исполнение
цепочек проверяем после чистой установки: внешний IP каждой категории, журналы,
отказ входа/выхода и отсутствие перехода на другой IP.

Mac-сторож не входит в переносимый конфиг. Перед включением новой маршрутизации
Claude его ожидаемый IP нужно обновить: пока он ожидает прежний выход Claude.
VPN не отключается и не переподключается без отдельного согласования.
