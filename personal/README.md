# Персональный artme.conf

Семейная подписка `artem-public` содержит только серверы и не меняется этой сборкой.
Персональный `artme.conf` — полный профиль с серверами, правилами и цепочками,
публикуемый отдельно в secret Gist. Секретный Gist доступен любому, кто знает ссылку;
полный файл и ссылки на него не коммитятся в публичный репозиторий.

На iPhone Shadowrocket 2.2.93 подтверждены цепочки через группу, четыре IP-маршрута
и обмен голосовым UDP; пользователь подтвердил ожидаемые IP и неплохое качество голоса.
На Mac установлена 2.2.69: цепочка через группу на ней не заработала.
Автоматическое переключение при отказе входа и остановка при отказе ISP ещё не проверены.

## Как идёт трафик

```text
OpenAI → OPENAI → ISP-OPENAI → Proxy Pass: artem-personal → выбранный VPN → ISP → сайт
Claude → CLAUDE → ISP-CLAUDE → Proxy Pass: artem-personal → выбранный VPN → ISP → сайт
OTHER  → artem-personal → выбранный VPN → сайт
DIRECT → сайт напрямую
```

Стрелки в первых двух строках показывают выбор политик. Физический путь:
устройство → VPN → ISP → сайт. `SERVICE` объединяет ISP-узлы для просмотра;
правила обращаются к отдельным OPENAI и CLAUDE, поэтому выбор SERVICE не меняет их.

- `artem-personal`: ручной выбор входа или AUTO, исходно AUTO.
- `AUTO`: fallback по порядку из `artme.json`, Xeovo New York → Xeovo Las Vegas →
  Blanc New York → Blanc Frankfurt → Blanc Almaty. Интервал 120 секунд, timeout 5 секунд.
  Это порядок доступности, не выбор минимальной задержки.
- `ISP-OPENAI`, `ISP-CLAUDE`: последние выбранные реквизиты IPRoyal Multi-device,
  SOCKS5 UDP включён; оба содержат `chain=artem-personal`.
- OPENAI и CLAUDE допускают только собственный ISP или REJECT. Запасного VPN/DIRECT
  с другим выходным IP нет. `close-if-proxy-chain-missing=true` запрещает пропуск входа.
- OTHER по умолчанию использует только VPN. При необходимости ему можно назначить
  собственный ISP через `routes.OTHER.mode=isp`, `exit` и `udp`.

Проверка AUTO измеряет доступность VPN до gstatic, а не работоспособность всей
цепочки до IPRoyal. Доступный VPN может оказаться несовместим с ISP в конкретной
сети. В этом случае вручную выбрать другой вход в artem-personal. Переключение
не сохраняет уже открытые TCP/голосовые сессии и может потребовать их повторного открытия.
Разные серверы/выходы Blanc способны расходовать несколько source-IP слотов IPRoyal.

## Состав полного файла

- `[General]`: DNS из базы, update-url на персональную публикацию, запрет прямого
  обхода отсутствующего родителя и неподдерживаемого UDP. Удалён DoT `1.1.1.2`,
  который в нативных логах не проходил проверку сертификата. Проверка TLS не отключается.
  Системный fallback DNS из базы сохранён; полной изоляции DNS эта версия не обещает.
- `[Proxy]`: пять VLESS-входов с уникальными именами `AR-*`, два сервисных ISP-выхода.
  Для Xeovo WebSocket используется нативный `obfs-uri`, а не игнорируемый `path`.
- `[Proxy Group]`: AUTO, artem-personal, SERVICE, OPENAI, CLAUDE, OTHER.
- `[Rule]`: официальные голосовые IP OpenAI перед GEOIP, собственные домены сервисов,
  актуальные inbound IP Claude, сохранённые DIRECT-исключения и встроенный Zoom.

Официальный голосовой список загружается при каждой сборке. Уже опубликованный
файл не изменится сам: нужны повторная сборка, публикация и обновление на устройстве.
Общие сторонние CDN и сервисы авторизации целиком в AI-группы не направляются.
Роутинг по доменам/IP не гарантирует распознавание любого будущего адреса приложения.

## Где менять параметры

| Файл | Назначение |
|---|---|
| `artme.json` | Серверы, приоритет AUTO, исходный ручной выбор, ISP для категорий |
| `secrets.local.json` | URLs подписок, `exits.<ключ>.server/port/username/password`; Git игнорирует |
| `publish.local.json` | `owner`, `gist` персональной публикации; Git игнорирует |
| `../artme.conf` | Базовые DNS и правила; это прежний профиль, не полный персональный файл |
| `../tools/assemble_artme.py` | Преобразование подписок и сборка полного профиля |

Для замены ISP одной категории добавить реквизиты в локальный файл секретов и
поменять `routes.OPENAI.exit` или `routes.CLAUDE.exit`. Для приоритета другого VPN
изменить `rotation.priority`; для закрепления входа — `rotation.selected`.
Все ключи из подписок получает сборщик; на устройства приходит уже полный файл.

## Сборка и публикация

Из корня репозитория:

```sh
uv run tools/assemble_artme.py
uv run tools/assemble_artme.py --publish
```

Результат `out/artme.conf` имеет права 600. Публикация проверяет владельца и
`public=false`, сохраняет прежнее содержимое в `out/publication-before.private.json`,
изменяет только `artme.conf`, сверяет его байты через API и сохранность других файлов.
URL записывается в `out/artme-url.txt`. Старый телефонный тестовый файл остаётся
доступен по прежнему адресу для отката. Семейная подписка не затрагивается.

Для повторения текущей сборки из сохранённых снимков:

```sh
uv run tools/assemble_artme.py --sources-dir out/finalization/sources
```

Обычная подписка на серверы не заменяет полный Config-профиль с правилами.
Импортировать персональную ссылку следует через **Config → Download from URL → Use Config**.
Включить **Global Routing = Config**. В режиме Proxy правила категорий обходятся.
На чистом устройстве отдельные серверные подписки и ручной Proxy Pass не требуются
для проверенного на iPhone импорта; приложение показало привязку обоих ISP к artem-personal.
Для GEOIP,RU нужна Country-геобаза. Сохранённый в UI выбор может перекрывать
`policy-select-name`: проверить, что artem-personal = AUTO.

## Проверка на iPhone

Сначала сохранить прежний профиль; не удалять рабочие серверы.

| Адрес | Ожидаемый маршрут |
|---|---|
| `https://api.ipify.org` | OPENAI → текущий IPRoyal |
| `https://icanhazip.com` | CLAUDE → тот же IPRoyal |
| `https://checkip.amazonaws.com` | OTHER → VPN |
| `https://ifconfig.me/ip` | DIRECT → провайдер устройства |

Точный `checkip.amazonaws.com` намеренно переопределяет старое DIRECT-правило.
Лучше открыть свежие запросы, чтобы не принять кэш или старую сессию за новый маршрут.
Совпадение IP — быстрая проверка; журнал должен отдельно подтвердить входной VPN
и ISP-узел. Затем проверить ChatGPT, Claude и голос. UDP-поддержка подтверждена
отдельными сетевыми пробами, но не гарантирует хорошую голосовую связь.

После нормального прохождения проверок отдельно проверить ручную смену входа,
AUTO при недоступности первого входа и остановку AI без смены IP при отказе ISP.
Последние проверки выполнять на тестовом устройстве, сохранив возможность отката.
Mac до обновления клиента на этот профиль автоматически не переключать.
Watcher и kill switch не включать; VPN не выключать и не перезапускать без согласования.

## Отдельный кандидат пула

Для проверки нового набора входов сборщик поддерживает `--settings`, `--filename`
и `--output-dir`. Папка вывода полного файла обязана находиться внутри ignored out/.
Это позволяет опубликовать тестовую копию со своим update-url, сохраняя основной
профиль и его узлы. Отбор 5+5 и ограничения измерений описаны в
[журнале пула](../docs/network-lab/2026-11-03/entry-pool.md).
