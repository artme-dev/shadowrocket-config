# Отбор входного пула Blanc и Xeovo

Пользователь подтвердил приоритет: баланс AI через ISP и обычного VPN. Отбор
проводился после успешной телефонной проверки основного профиля; входной IP
не определяет закреплённый ISP-выход AI. Для OTHER входной VPN остаётся выходом.

## Метод и границы

Рассмотрены 34 разных конфигурации входов. Для каждой — три коротких HTTPS-запроса
к Cloudflare через отдельный sing-box, привязанный к en0. Для финальных десяти —
повторные три запроса и по одной загрузке 2 000 000 байт. Все десять загрузок полные,
HTTP 200; всего 20 000 000 байт. Процессы завершены, рабочий VPN не переключался.

Это предварительный отбор входов с одной сети Mac. Cloudflare использует anycast;
маршрут до него не равен маршруту до ISP. Маленькая загрузка не измеряет длительную
пропускную способность. TTFB включает новое HTTPS-соединение к сайту; Hysteria2
может повторно использовать внешнее QUIC-соединение между запросами. Здесь не
измерены потери UDP, jitter, восстановление после отказа и качество на мобильной сети.

На этом этапе ISP не использовался: перебор многих источников мог занять source-IP
слоты IPRoyal. Для новых входов полная цепочка и нативный импорт Hysteria2 остаются
отдельными проверками. Рабочий Xeovo New York сохраняется первым до таких проверок.

## Почему такой состав

- Blanc: Amsterdam, Zurich, Frankfurt, Almaty, Oulu. Это пять разных адресов
  `server:port` из шести, имеющихся в снимке 50 узлов. Разные названия сами по себе
  не гарантируют разные входы: например, Frankfurt, New York и Warsaw используют
  один адрес. Разные адреса также не доказывают независимость инфраструктуры.
- Xeovo: New York WS, Netherlands HY2, Germany HY2, Sweden WS, Singapore WS.
  Сингапур медленнее, но оставлен последним резервом с другим географическим маршрутом.
- В проверенной сети из 18 протестированных WS-вариантов Xeovo прошли только три;
  остальные вернули ошибки WebSocket или TCP timeout. Это не утверждение об их
  недоступности на других сетях. Из четырёх HY2 прошли три; Sweden HY2 имел выброс
  первого байта до 2.855 с и в финальный набор не включён.
- Первый первоначальный запуск не протестировал Xeovo: системный DNS возвращал
  fake-IP Shadowrocket 198.18/15. Это исправлено получением публичных адресов через
  проверяемый HTTPS DNS. Нулевые попытки из первого отчёта не считались отказами серверов.

AUTO остаётся fallback, не случайным ротейтом: New York → Netherlands HY2 →
Germany HY2 → Sweden WS → пять Blanc → Singapore WS. Это сохраняет приоритет
Xeovo без помещения медленного Сингапура перед всем резервом Blanc.

## Артефакты и воспроизведение

Полные входы, сырые результаты, конфиги и ссылка на отдельный тестовый профиль
сохранены в ignored `out/entry-pool/`. Основной `personal/artme.json` и опубликованный
`artme.conf` этим отбором не заменялись. Копия с пулом называется `artme-pool-test.conf`.
Её правила, DNS, ISP и retained узлы совпадают с основным профилем; отличается
набор входов, порядок AUTO и собственный update-url. На Mac она не активировалась.

Общий инструмент отбора: `tools/benchmark_entries.py`. Вход — приватный JSON массив
Clash-подобных VLESS/Hysteria2 узлов с безопасными названиями. Пример запуска из корня:

```sh
python3 tools/benchmark_entries.py \
  --nodes out/entry-pool/selected-candidates.private.json \
  --output out/entry-pool/recheck \
  --interface en0 --download-bytes 2000000
```

Повторный запуск снова расходует 20 МБ. Без `--download-bytes` выполняются только
короткие HTTPS-запросы. Конфиги не меняют системную маршрутизацию, ISP не используют.

Сборка отдельного кандидата:

```sh
uv run tools/assemble_artme.py \
  --settings out/entry-pool/pool-candidate.settings.json \
  --filename artme-pool-test.conf --output-dir out/entry-pool/build \
  --sources-dir out/finalization/sources
```

Добавление `--publish` обновляет только указанный файл в существующем secret Gist.
Основной профиль и семейная подписка сохраняются. Прежде чем продвигать пул в
основной профиль, проверить новые входы с ISP на телефоне, затем отказоустойчивость.

## Дополнительная проверка полной цепочки Hysteria2

После отбора выполнены отдельные последовательные проверки Netherlands HY2 и
Germany HY2 с текущим IPRoyal. Каждый вход: 6 HTTPS trace-запросов (Cloudflare,
ChatGPT, Anthropic, два повтора) и 2 реальные SOCKS5 UDP DNS-проверки.
Все 12 TCP и 4 UDP проверки вернули ожидаемый закреплённый IP; отказов source-IP
слотов не было. Это проверка sing-box и провайдеров, не нативного Shadowrocket.
Большие загрузки через ISP не выполнялись. Оба тестовых процесса завершены.

Артефакты: ignored out/entry-pool/hy2-chain/. Нативный импорт и работа цепочек
через эти Hysteria2 в Shadowrocket, переключение при отказе и fail-closed ещё
остаются проверками приёмки. На момент попытки доступа Mac заблокирован; ранее
найденный app bundle по-прежнему содержит2.2.69 build2701. Обновление клиента
может прервать VPN и требует отдельного согласования пользователя.
