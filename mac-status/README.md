# AI Network — личный монитор macOS

Нативное приложение SwiftUI + AppKit для macOS 26+. Значок в строке меню
открывает компактную стеклянную панель; «Подробнее…» — окно с маршрутами и
состоянием защиты. При запуске открывается компактная панель. Без автозапуска
при входе в систему. Версия 1.1 переработана по референсам Control Center, Wi‑Fi
и Battery macOS 27: одна системная glass-поверхность, простые строки/разделители,
системная типографика и отсутствие вложенных карточек.

## Только чтение

Приложение читает локальный status.json watcher, ожидаемые IP из подготовленной
политики, принятый отчёт проверки блокировки и состояния двух заданий launchd.
Выполняет только `launchctl print` и `route -n get default` с фиксированными
аргументами. Нет shell, sudo, IP-проб, изменения настроек, публикаций, сигналов
сторонним процессам или управления VPN. Обновление — повторное чтение локальных
данных, а не принудительный сетевой тест. Чтение выполняется вне UI-потока.

Данные перечитываются каждые 15 секунд. Сами IP-пробы по-прежнему выполняет watcher
раз в минуту. Отчёт старше 150 секунд, время более чем на 30 секунд из будущего, смена туннеля или ожидаемого
IP, пустые проверки и отсутствующие службы не дают зелёный общий статус.
Свежий подтверждённый wrong_exit выделяется красным. Успешно завершившееся
периодическое задание в состоянии not running означает ожидание следующего
запуска, а не выключенную защиту.

**Состояние службы kill switch и состояние правил PF различаются.** Текущие
правила ядра приложение не проверяет, так как для этого нужны права администратора.
Видны загрузка/результат службы и дата сохранённой проверки блокировки. Зелёный
заголовок означает подтверждённые маршруты при здоровых службах, а не новую
проверку всего firewall. Это явно пояснено в подробностях и копируемой сводке.

Кнопка копирования по запросу пользователя помещает в буфер сводку с IP/временем/
статусами. Ключи, пароли и URL подписок не читаются и не включаются. Кнопка журнала
показывает локальный файл в Finder. Выход закрывает только монитор; watcher,
firewall и VPN продолжают работать. Доступ Accessibility монитору не требуется.
Приложение не отправляет телеметрию и не подключается к сети.

## Запуск и сборка

Установленная личная копия: `~/Applications/AI Network.app`.
Исходники: `mac-status/Sources/`; бинарные артефакты — в ignored out/mac-status/.
Нужен macOS 26+ и Apple Command Line Tools с SDK, содержащим NSGlassEffectView. Сборка без внешних
зависимостей и без изменения выбора Xcode или принятия лицензий:

```sh
./mac-status/build.sh
```

Скрипт создаёт `.app`, иконку и локальную ad-hoc подпись, затем запускает 18 проверок
модели состояния. Собирается архитектура текущего Mac. Для распространения другим
пользователям нужны отдельные подпись/нотаризация; текущая сборка личная.

```sh
"out/mac-status/AI Network.app/Contents/MacOS/AI Network" --self-test
"out/mac-status/AI Network.app/Contents/MacOS/AI Network" --read-snapshot
```

Пути данных рассчитаны на существующий проект в
`~/custom-network/shadowrocket-config` и текущие локальные задания mac-guards.
Отсутствие данных отображается как неизвестное состояние. Политика и журналы
из out/ не включаются в bundle и не коммитятся.

## Интерфейс

- Настоящий NSGlassEffectView, размещённый в прозрачной NSPanel. Нет непрозрачного
  системного popover под glass и нарисованного серого фона. Панель без стрелки
  привязана к статусному значку и ограничена видимой областью текущего экрана.
- HUD-оформление с белым содержимым и системным адаптивным стеклом по референсам
  Control Center. Цветные символы не должны вымываться автоматической vibrancy.
- Системные SF Symbols, шрифты, NSToolbar, меню и клавиатурные команды.
  Цвета состояния дополнены текстом/символами; фиктивных переключателей нет.
- IP можно выделять и копировать; элементы имеют accessibility labels и подсказки.
- Cmd+R перечитывает данные. Меню приложения: Cmd+1 — компактный статус,
  Cmd+2 — подробности. Cmd+W закрывает окно, Cmd+Q завершает монитор.
  Esc закрывает панель и возвращает фокус предыдущему приложению.
- Из меню строки состояния можно открыть подробности или выйти из монитора.

## Проверка

Модель проверяется изолированными сценариями без остановки VPN или изменения
живых статусов watcher: свежесть, будущее время, несовпадение IP, пустые данные,
смена политики/интерфейса, выключенные службы и разбор вывода launchd. Живое
чтение сверяется с реальными локальными файлами. Первая версия проверялась на Mac в светлом/тёмном QA-окне и в popover. Для
версии 1.1 проверены настоящее системное стекло, отсутствие автоматической рамки
фокуса, Tab/Space, Cmd+1/Esc, уход в другое приложение, Cmd+W, повторное открытие
подробностей, обновление и подтверждение копирования.
Системная тема пользователя при этом не меняется.

## Обновление личной копии

Выйти из AI Network через его меню, выполнить сборку и скопировать bundle:

```sh
ditto "out/mac-status/AI Network.app" "$HOME/Applications/AI Network.app"
```

Затем открыть приложение из Applications. Эта операция заменяет только UI,
не перезапускает watcher/firewall/VPN. Сборка подписана локально для личного Mac.
QA-копии приложения и протокол проверки находятся только в ignored out/mac-status/;
после проверки оставлена одна установленная рабочая копия, тестовые процессы закрыты.

## Решения по дизайну 1.1

- Референсы пользователя — системные панели Control Center, Battery и Wi‑Fi macOS 27.
- Основная поверхность: NSGlassEffectView, без ручной имитации blur/градиентного фона.
- Чёрно-белый статусный символ меняет форму; основной цвет состояния виден внутри панели.
- Обновление не меняет размеры строк/положение пунктов; исправность и время данных разделены.
- Служба firewall и проверка реальной блокировки по-прежнему не смешиваются в один показатель.
- Различия UI не меняют модель чтения и не запускают проверки/установку защиты.

### Результат прохода 1.1

Живая проверка выполнена на установленной копии 7 ноября 2026. Вариант clear
отклонён из-за плохой читаемости на светлом фоне; оставлен regular. Foreground
вынесен поверх glass отдельным прозрачным hosting view, чтобы vibrancy не
вымывала реальные цвета иконок. При наличии установленных ChatGPT/Claude их
иконки читаются через NSWorkspace, без скачивания; иначе используется SF Symbol.

Заголовки доступны как accessibility headings. Цвет и форма состояния дополняются
текстом; защищённый/неизвестный/устаревший статус определяется прежней моделью.
Время проверки есть и в tooltip статусного значка. Повторное открытие не перебивает
видимое окно подробностей; меню умеет стандартное закрытие и свертывание.
Исходная версия сохранена локально в out/mac-status/AI Network 1.0.app;
текущий протокол QA — out/mac-status/glass-review.private.json.
